Gaze repo OpenSpec delta template: every specs/<capability>/spec.md delta ends with explicit `## MODIFIED Requirements` and `## REMOVED Requirements` sections containing "None." when empty (uniform precedent: reusable-gaze-ai-report, init-ci-scaffold, validate-workflow-floor deltas; meta-prompt pack MP-013 requires a REMOVED section with no removals to say so explicitly). New deltas that stop after `## ADDED Requirements` deviate from the template — check for the trailing sections when authoring or reviewin
